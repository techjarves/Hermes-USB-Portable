UBUNTU AND HERMES BY ACHU - UNIVERSAL DUAL BOOT SUITE (BIOS + UEFI)
============================================================================
Signature Edition: Designed & Built by Achu Pradeep

1. BOOTING ON OLD GENERATION SYSTEMS (LEGACY BIOS / CSM):
   - Insert USB into the PC.
   - Power on and press your Boot Menu key (F12, F11, F8, F9, or Esc).
   - Select USB-HDD / Kingston DataTraveler.
   - The custom boot screen will appear: "UBUNTU AND HERMES BY ACHU".
   - Select 'Ubuntu and Hermes by Achu' and press Enter.

2. BOOTING ON NEW GENERATION SYSTEMS (UEFI):
   - Insert USB into the PC.
   - Power on and press Boot Menu key.
   - Select UEFI: Kingston DataTraveler (Partition 2 / VTOYEFI).
   - The high-resolution custom boot screen will appear: "UBUNTU AND HERMES BY ACHU".
   - Select 'Ubuntu and Hermes by Achu' and press Enter.

3. USING HERMES PORTABLE INSIDE UBUNTU (LIVE OR INSTALLED):
   - Open a terminal in Ubuntu.
   - Run:
       cd /media/ubuntu/*
       ./setup-live-ubuntu.sh
   - Or simply execute:
       ./run-hermes.sh
   - A Desktop shortcut 'Hermes Agent Portable' will be added to your desktop.
   - All your pre-cached linux-x64 runtimes and synced Obsidian Brain are active!
